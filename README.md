# そしま麻雀

iPhone専用の麻雀スコア・精算記録アプリの初期実装です。SwiftUI / iOS 17以降。外部サービス、アカウント、サーバーは使いません。

## 使い方

1. 「ルール」で開始点・返し点・ウマ・金額換算の単価を設定します。初期値はMリーグの点数ルールで、金額換算はオフです。
2. 「点数入力」で4人の名前と半荘終了時の持ち点を入力します。供託は受け取り先の持ち点に加算してください。
3. 「結果を確認する」でスコアの内訳と支払い先を確認し、「この結果を保存」を押します。
4. 「記録」で半荘ごとの結果と累計収支を確認します。記録を左にスワイプすると、確認後に削除できます。

入力途中の値・ルール・記録は端末内のApplication Support/Soshima/records.jsonに保存します。保存失敗は画面に表示し、読み込み不能時は元のファイルを上書きしません。アプリ削除時にデータは失われます。

## 計算ルール

- スコア =（最終持ち点 − 返し点）÷ 1,000 + ウマ + オカ。
- オカ合計 =（返し点 − 開始点）× 4。1位へ加算します。
- Mリーグ設定：25,000点持ち、30,000点返し、ウマ +30 / +10 / −10 / −30、オカ20,000点。
- 例：42,000 / 31,000 / 18,000 / 9,000点 → +62.0 / +11.0 / −22.0 / −51.0。
- 同点は該当順位のウマを均等配分。1位同点はオカも均等配分します。座順優先にはしません。
- 内部計算は1/60スコア単位の整数で行い、3人同点でも合計0を保持します。表示は小数1桁なので、同点時は表示値の合計に丸め差が出ることがあります。
- 円換算は丸め前のスコアに設定単価を掛け、最大剰余法で1円単位に調整します。同じ端数なら結果の表示順を優先します。受け取りと支払いの合計は一致します。
- 金額換算と支払い案はアプリ独自機能です。Mリーグの金銭精算ルールを意味しません。
- 持ち点は100点単位。合計不一致、名前重複、ウマ合計が0以外の記録は保存しません。

## Macで起動

Xcode 16以降で `Soshima.xcodeproj` を開き、`Soshima` スキームとiPhoneシミュレーターを選んで実行してください。実機に入れる場合はSigning & Capabilitiesで自身のTeamを選択します。Bundle IDの変更が必要なら各自のIDに変更してください。

```sh
cd /path/to/soshimahjong
xcodebuild -project Soshima.xcodeproj -scheme Soshima \
  -sdk iphonesimulator -configuration Debug \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO build
```

## 計算テスト

Swift 5.9以降で実行できます。XcodeなしのLinuxでも計算部分を検証できます。

```sh
cd /path/to/soshimahjong
swift test
```

このクラウドではSwift 6.0.3で計算テスト13件を実行しました。iOSのSDKがないため、SwiftUI画面の型チェック・iOSビルド・シミュレーター操作は未検証です。構文解析だけでiOSビルド成功とは扱っていません。

## 初期版の範囲とリリース前の作業

現状は同じ4人での記録用です。名前を編集しても各入力枠の参加者IDは維持されます。別メンバーの対局管理、期間別集計、記録の編集、入出金済み管理、データ書き出し・復元は未実装です。記録を訂正する場合は削除して入力し直してください。

App Storeへの公開はしていません。Macでのビルドと実機確認、アプリアイコン、署名、ストア情報とプライバシー情報の準備が必要です。大きい文字サイズ、ダークモード、VoiceOver、キーボード操作、保存後の再起動、履歴削除を実機でも確認してください。

クラウド作業は既存のチェックアウトをそのまま使用します。ユーザーの明示的な依頼がなければGit worktreeは作成しません。

## レビュー反映（入力と飛び終了）

- 赤を基調とし、点数・金額は半角の数字で表示します。
- 名前欄と点数欄の両方をフォーカス管理し、キーボード上の「完了」で閉じます。「次へ」で名前から点数、次の点数へ移動できます。
- 「1スコアあたりの円」は、換算なし / 30 / 50 / 100 / 200 / 500 / 1000 / その他のメニューから選びます。「その他」は直接入力です。
- 「ルール」で飛び終了をオンにすると、最終持ち点が0点未満の対局を飛び終了として保存します。0点ちょうどは対象外です。対局中の自動検知機能はありません。
- 飛びボーナスは0〜1000スコアで設定し、初期値は10です。飛んだ人から飛ばした人へ移します。0ならボーナスなしです。
- 飛んだ人がいる場合は、点数入力画面で飛ばした人を選択します。複数人が飛んだ場合は、それぞれ選択が必要です。飛んだ本人と他の飛んだ人は受取先にできません。
- Mリーグのプリセットは飛び終了なしです。プリセット選択後に飛び終了をオンにするとカスタムルールとして使えます。
- 古い保存データは飛び終了オフとして読み込み、過去のスコアを変えません。

Macで最新版のファイルに更新し、元と同じBundle IDとTeamで実行してください。既存記録を保持するため、iPhoneからアプリを削除する必要はありません。入力の使いやすさとキーボードの動作は実機確認が必要です。
